Политика конфиденциальности

Настоящая политика описывает базовые принципы обработки данных посетителей сайта WEB00 Pro. Текст является рабочим шаблоном для первой версии сайта и должен быть уточнён перед публичным запуском с учётом фактических реквизитов владельца сайта и подключённых сервисов.

1. Какие данные могут обрабатываться

При отправке заявки пользователь может указать имя, контакт для связи, тип задачи, бюджет и комментарий. Эти данные используются только для связи с пользователем и подготовки расчёта проекта.

2. Цели обработки

Данные используются для обработки входящих обращений, консультации по услугам, подготовки коммерческого предложения и дальнейшей коммуникации по проекту.

3. Передача данных

Данные не продаются третьим лицам. Передача возможна только если это необходимо для исполнения запроса пользователя, соблюдения закона или подключения согласованных пользователем сервисов.

4. Хранение и защита

В первой версии сайта форма не отправляет данные на сервер. После подключения backend-обработчика должны быть настроены разумные меры защиты, ограничение доступа и сроки хранения.

5. Права пользователя

Пользователь может запросить уточнение, удаление или прекращение обработки своих данных, направив обращение через доступные контакты WEB00 Pro.

6. Изменения политики

Политика может обновляться при изменении функциональности сайта, подключении аналитики, форм отправки, мессенджеров или иных сервисов.
