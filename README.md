# WEB00 Pro

Профессиональный лендинг WEB00 для услуг создания сайтов, готовых решений и Telegram-ботов для малого бизнеса.

## Цель проекта

Создать современный коммерческий сайт для продажи услуг:

- лендинги под ключ;
- сайты для малого бизнеса;
- каталоги и мини-магазины;
- Telegram-боты;
- доработка существующих сайтов.
