# WEB00 Pro

WEB00 Pro - статический премиальный сайт для продажи услуг создания сайтов, лендингов, каталогов, мини-магазинов, готовых решений и Telegram-ботов для малого бизнеса.

Текущая версия пересобрана как dark-tech Site UI с многостраничной структурой: главная, услуги, каталог решений, процесс работы, цены, FAQ, контакты и frontend-only статусы заявок.

## Структура проекта

- `index.html` - короткая главная страница с hero, результатом после запуска и карточками перехода.
- `services.html` - услуги WEB00 Pro и блок выбора формата работы.
- `solutions.html` - каталог готовых решений, фильтры, detail modal, demo viewer и заявка на выбранное решение.
- `how-it-works.html` - процесс работы, этапы проекта, результат для клиента и CTA.
- `pricing.html` - цены, факторы стоимости и frontend-only калькулятор.
- `faq.html` - FAQ с категориями и accordion.
- `contacts.html` - контакты, форма связи, проверка статуса заявки и кнопка сообщения об ошибке.
- `status.html` - frontend-only страница проверки статуса заявки и демонстрации состояний 21-30.
- `privacy-policy.html` - базовая политика конфиденциальности.
- `consent-personal-data.html` - базовое согласие на обработку персональных данных.
- `robots.txt` - правила индексации.
- `sitemap.xml` - карта сайта.
- `assets/css/styles.css` - общий дизайн, сетки, адаптив и компоненты.
- `assets/js/data.js` - backend-ready структуры данных, mock-заявки, mock-статусы и localStorage-заглушки.
- `assets/js/main.js` - многостраничная навигация, active state, фильтры, FAQ, модалки, калькулятор, форма заявки, bug report и статусы.
- `landings/` - нишевые страницы готовых решений.
- `demos/` - внутренняя библиотека локальных demo-страниц для просмотра внутри WEB00 Pro.

## Названия карточек со старого WEB00

В `assets/js/data.js` у карточек готовых решений есть поля `legacyTitle`, `title` и `editableTitle`. `legacyTitle` хранит точное название со старого сайта, `title` используется в текущем интерфейсе, а `editableTitle: true` оставлен под будущую админку, где названия можно будет менять без правки кода.

## Как открыть локально

Откройте `index.html` в браузере двойным кликом или через локальный статический сервер. Верхнее меню ведёт на отдельные `.html` страницы. Сборщик, npm и backend не требуются.

## Что пока не подключено

- Реальная отправка формы на сервер.
- Cloudflare Worker или другой backend-обработчик заявок.
- Telegram Bot API для автоматических уведомлений.
- Реальная база данных заявок и обращений об ошибках.
- Аналитика, CRM и платёжные сервисы.
- Финальные юридические реквизиты владельца сайта.

## Что дальше

1. Уточнить реальные контакты Telegram, VK и Max.
2. Подставить финальный домен в `canonical`, `robots.txt` и `sitemap.xml`.
3. Подключить Cloudflare Worker/API вместо localStorage-заглушек в `assets/js/data.js`.
4. Подключить админку/API для редактирования `title`, активности карточек и контента.
5. Провести финальный QAMax-этап после подключения backend.
